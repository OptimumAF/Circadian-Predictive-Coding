## Critical path and next action

#160 software and this narrow native investigation are complete. The question of
learning a new task while retaining an acquired task and recovering on return
remains open, as do R2/R4/R5.1/R5.3/G5/R7 and release requirements. The old-task
compatibility failure makes another cold checkpoint diagnostic a poor next step.

Next implementation action: inspect the existing bounded linear learner/update
and stream ports, then add the smallest role-preserving sequential correction
path for the wide categorical control, with literal acquisition/interference/
return tests before any scientific invocation. Keep a minimum-change update
separate from a cold refit and account explicitly for any replay rows. Prefer
existing update behavior if inspection finds it. Freeze any cache-backed study
and simple replay/current-only controls separately before opening the paid bank;
do not re-extract the8B model or infer a native/CPC advantage from this result.

Live scope, evidence and handoff belong to GitHub issues. Historical plans and
development log are deliberately unchanged under current AGENTS.md.
