# Public-cue isolated probes: existing interface qualified

The current two-head recurrent learner works directly with the existing generic
fresh-task probe, old-TRAIN monitors and fixed fresh-task/old-task return path.
No production adapter, algorithm or wrapper was needed. The same disposable
owner can also be read by the existing qualified endpoint observer.

Sixteen focused scripted cases passed on Windows and Linux. The affected
return case passed again with before/after-clock endpoint reads. They check
both head counters, complete episodes, full parameters/gradients/optimizer
ownership, actual actor and benchmark-budget isolation, role/data refusal,
paid successes followed by failed native returns, and preceding fresh-task
evidence retained when return fails. No Torch computation, physics or TRAIN/
archive file reads were run. The scripted counters and uniform predictions
are not learned behavior or numerical native interoperability evidence.

One shared fixture setup failure was preserved: it supplied an unsupported
replay limit to the benchmark runtime. The fixture was corrected without
changing production. Cumulative caps held: Windows12.8230s/456scripted adapter
entries/3874snapshot copies; Linux16.2763s/332entries/2839copies. Scoped
Ruff/format/fresh Windows mypy passed. No independent, full-suite, clean-clone,
packaging or release acceptance is claimed.

costs and failures in `artifacts/runs/public-cue-probe-compatibility-20261025/RESULTS.md`.
