# Shared-head joint LS rehearsal on an isolated probe

The ordinary single-head reserved probe can explicitly combine each private
update with two original, arrived source TRAIN packets. It uses the existing
minimum-change LS operation and generic fresh-task/return runner. It does not
update the source, benchmark or deployed actor.

```powershell
.venv/Scripts/python.exe -B -m scripts.recurring_ticket_workflow_example --method linear_fit --context-return --reserved-probe --probe-update minimum_change --train-update minimum_change --probe-rehearsal joint --output NEW-D-PATH.json
```

Use `--probe-rehearsal current_only` for the equal-row control. Omitting the
option preserves the existing sequential probe. Source `--train-update` remains
independent: omit it for the old cold source operation. Separate heads/paired
serving retain their prior interfaces; this new ordinary callback requires one
shared head, replay=none and the explicit minimum-change probe choice.

The source grants replay permission at its own birth, before recording any
experience. The handoff checks its live TRAIN-only owner, original12commits,
experience/label/receipt metadata and data, unchanged12/72 snapshot and original
consent. It retains the first A and first B six-row packets (indices0 and4),
using no task score or future label. Changed source data, replaced receipts,
foreign actor/version or unobserved public exposure changes refuse more work.
The read-only diagnostic monitors and probe_test data supply no fitting labels.
Private probe_train rows are transient; no source TRAIN bank retains them.

Each F update has its original3rows plus12retained rows:15fit rows. Each return
update has its original6rows plus12retained:18fit rows. Duplicates count as
exposures; there is no silent deduplication or reweighting. The current-only
control validates the same source information, then repeats the complete current
packet to the same15/18rows. Equal rows are not equal SVD work or an efficiency
claim. No joint-retention or scientific benefit is assumed.

Add `--probe-return-once` to either control for the explicit alternative return
recipe. Fresh updates still fit15rows. Each old return must match exactly one
whole certified source TRAIN packet; its duplicate retained copy is removed,
leaving current6+otherTRAIN6=12rows. Both original packets are still validated.
Partial, ambiguous, conflicting or nonmatching return data refuse further work.
The current-only control repeats current6 twice to the same12rows. Packet choice
uses original TRAIN data, never outcome/monitor/probe_test scores.

This option creates its own32-admission/288-extra-row auxiliary authority at
birth: F192additional rows plus return96. Original source/F/return clocks and
budgets remain. A complete case would fit44times/504rows, including duplicated
source training, versus44/600 for the original recipe. Admissions and expected
6/12extra-row charges precede composition; a failed match keeps its6-row charge.
No unreadable application is credited as known. The original default/results stay.
The initial delivery was software-only. A subsequent independently reviewed
[fixed native comparison](reports/shared-linear-once-comparison-20261031.md)
finished joint6/6 versus current-only5/6 known tasks; both fresh tasks already
passed before fitting, so new-task acquisition remains unproved. This descriptive
case does not establish general retention, efficiency or CPC benefit. The earlier
[18-row-return comparison](reports/shared-linear-probe-comparison-20261031.md)
ended with the same failure in both arms and remains unchanged. No automatic
retry, further dose/weight search or renewed native allowance follows.
[Once-return software evidence](reports/shared-linear-once-return-20261031.md).

For the original default recipe, the source12-update/30-second/512-MiB authority and independent F16/
return16 authorities remain unchanged. Additional work has one separate
32-admission/384-extra-row/30-second/512-MiB auxiliary session, born once. Its
admissions/exposures are charged before packet construction/fitting and survive
failure. Source time continues to run; the auxiliary budget never renews it.

For the original default recipe, a complete execution fits source12/72rows and private32/528rows total
44fits600rows. This is expected work for a later genuine case, not an experiment
executed by this software delivery. Failed/lost returns retain known applications
and mark unreturned work or application uncertainty; no further callback is
admitted after an incomplete prior event. Public evidence cannot erase the
private paid ledger, and observed foreign budget values do not replace original
limits, birth or charges in preserved evidence.

Report fields keep costs distinct:

- `training_work` and source `budget`: original source updates only.
- `probe_updates`: applied private LS callbacks, or null when application cannot
  be observed. `application_unknown_updates` keeps that uncertainty separate from
  the known applied prefix.
- `probe_replay_examples`: permanent additional row charges, including repeated
  current rows in the current-only control.
- Private `preserved_training_work`: legacy direct train-batch ports; zero for
  this callback route, not zero private fitting.
- `preserved_linear_rehearsal_work`: admissions, returned/applied callbacks,
  additional rows, original auxiliary budget and bounded32event receipts.
- Per-event `fit_attempts`/`fit_returns`: LS owner-port admissions/returns;
  `unreturned_fit_work_unknown` distinguishes lost physical work. This is not
  a complete kernel/FLOP meter. `native_sgd_updates` remains0.
- `reserved_probe_summary.reported_costs.linear_rehearsal`: separate scalar
  projection; missing values remain unknown.

The retained packets occupy960named array bytes and source guard arrays11,520B;
metadata, coefficient/state copies, validations and allocator work are additional.
Packet output bytes and snapshot API work are recorded, not all physical copies.
No new scientific comparison, baseline retuning or release qualification is
granted by this option. [Software evidence and limits](reports/shared-linear-joint-probe-20261030.md).
