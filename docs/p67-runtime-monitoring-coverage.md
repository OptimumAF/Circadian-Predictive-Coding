describes removal of a trace function after its error and its thread scope. The local
control records a real caught denial, automatically inactive hook and subsequent actual
target execution. This is not a thread-complete guard implementation.

The [function C-API](https://docs.python.org/3.14/c-api/function.html#c.PyFunction_GetDefaults)
