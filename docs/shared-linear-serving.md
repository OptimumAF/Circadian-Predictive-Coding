# Shared linear state at the serving boundary

`src.adapters.linear_fit_serving` binds the existing complete `LinearFitSnapshot`
to `PromotableActor`, `ServingPromotionController` and the existing typed serving
slot. It adds no learner, fit, runtime, replay authority or publication policy.
The updated checkout exposes the ordinary mode explicitly:

```text
python -m scripts.recurring_ticket_workflow_example --method linear_fit --context-return --train-update minimum_change --replay coverage --replay-joint joint --shared-serving --output NEW.json
```

The command performs training and needs a separately frozen local budget.
Ordinary lifecycle software checks use scripted source fits and guard utilities;
a full genuine serving qualification remains unexecuted. Existing development
wheels predate this option. `current_only` is the explicit equal-row control;
serving and joint replay remain opt-in. Conflicting private, reserved, contextual,
adaptive or catalog modes refuse before data.

With an existing declared live actor, fixed `DecisionFeatureSpec` and request:

```python
from src.adapters.linear_fit_serving import LinearFitServingPredictor

reader = LinearFitServingPredictor(actor, spec)
observed = reader.serve(request)
# observed.generation, actor_version, completed_updates identify the actual slot.
result = observed.result
work = reader.native_work
```

Each call uses one detached complete actor slot from the existing serving lock.
The reader owns its original schema, validates exact shared geometry/model/counts,
and calls the unchanged frozen linear typed reader. Fitted and unfitted costs stay
separate. A lost typed return still pays completed native work; the existing
serving fault latch refuses later requests. No candidate read implies promotion.
Caller changes to its original schema do not alter the bound reader or guard.

`categorical_guard(spec, clock)` supplies the existing evaluator with shared-state
geometry validation and complete canonical record bytes/digests. The controller
still enforces arrived, disjoint `inner_guard` IDs and all existing promotion
criteria. Guards do not become TRAIN or replay. The caller must budget and record
their model reads/copies/latency/resource work; no fresh authority is granted by
constructing a guard. `build_linear(state)` constructs an unfitted owned learner;
the existing evaluator/controller restores the validated complete state. Snapshot
bytes are compact validated JSON including fit evidence and counters, not heap,
temporary copies, process RSS or compute. Contextual adapters retain their original
validation and refuse shared states; the shared adapter refuses contextual states.
