`8793c49ee4f9f8b07649e8db6571ed53746a9a06`. A Git commit below identifies
when an artifact entered the repository; it does **not** establish the commit
used to execute the run. No artifact is rewritten here. The vision benchmark
code used final test data for early stopping and sleep rollback, and its heads
and backbones were unmatched. Treat its rankings as legacy/test-informed until
the corrected protocol in [DEVELOPMENT_PLAN.md](../DEVELOPMENT_PLAN.md) is run.
