# A-only public21 camera control

This R4.5 control asks whether the accepted A-only nearest memory can act under
the known camera change and return to the original camera using the public21
input view. The existing frozen rollout and actual StableActor execute it;
there is no new learner, stream runner or training algorithm.

## Accepted local outcome

The single budgeted native case completed successfully and passed independent
artifact readback. Both shifted B and fresh original A succeeded in29controls,
with return1/any-final success/termination. Both full raw789 teacher trajectories
match exactly; action-bound violations are0. There was no new fit, append,
SGD, teacher or label acquisition. Public-B gains+1 on each frozen endpoint
versus the failed RGB A-only baseline; differences from RGB candidates and A
retention losses are all0. The simpler A-only input suffices in this exact
known fixture. This limits what the earlier RGB adaptation success demonstrates.

45new cases pass on each platform; scoped statics and independent source/gate/
actual review accept this result. Initial unused-import lint failure is retained
and repaired. The consumed native protocol admits no repeat or extra arm.

## Fixed data and ownership

The case qualifies the accepted A17 TRAIN episode, reads the accepted camera
case's frozen policy statistics and indexes only `warm_features`/`warm_actions`
from its NPZ. It validates all789 normalized prototype coordinates and actions
against A before copying the exact21-prefix into a matching typed policy. The
new source retains publication1/29rows and fitted_rows29. There is no new fit,
append, SGD or B training. Whole archive file size, warm array payload,
normalization validation and restored payload are reported separately.

Only after restoration does the case read the accepted camera teacher and
comparison traces, for read-only qualification/measurement. Their observation
and action exposures are counted. Those labels never reach a training call.
The same actual StableActor runs shifted B then fresh original A at physical17,
with the same controller, horizon50 and renderer. The first saved trace, source
and actor validate before the return episode. Exact returned/retained trace,
reported policy, projection, work and full-state/version checks guard admission.
Failures preserve exclusive output, attempted work and any paid trace.

## Endpoints and interpretation

Every complete outcome records sparse return, any/final success, end flags,
controls, action bounds and descriptive teacher reconstruction. Signed public21
minus accepted RGB warm/candidate outcomes and A-reference minus public-A
retention loss use the same three success endpoints. Success is not an admission
condition. All previous RGB warm failures and neural/offline negatives remain.

Raw789 traces, frame/pooling costs and full-source validation remain. Prototype
payload is5800B and statistics336B per public21 owner, versus183976B/12624B for
the accepted RGB owner. Distance coordinates are21 rather than789. Actual actor
distance counts are derived from typed state and returned query counts; selected
indices are not exposed. Two-owner payloads exclude temporary snapshots,
deepcopies and validation/archive arrays. The observer measures sampled tree
high-water plus final SELF, without proving lifetime-tree memory coverage.

This known-fixture control cannot establish generalization, visual invariance,
universal label necessity, neural learning, CPC advantage or deployed benefit.
Full R4.4/R4.5 and research/release requirements remain open.
