# ADR-0402: Admit optional realized-PC readouts at existing joint checkpoints

## Context

The detached TRAIN-only PC diagnostic is verified, but was not reachable from the
existing MiniGrid acquisition pilot. The pilot already owns checkpoint budgets,
source/actor isolation, fixed TRAIN readouts and protected paid evidence. Repeating
that orchestration would add another state and budget authority.

## Decision

Add one strict API/CLI option for explicit joint PC/neutral methods, at0/128 only.
Reuse the existing guarded readout helper with optional catalogue groups/call-kind/
exact-evidence arguments; preserve all existing defaults. One group contains all
six original TRAIN episodes,54rows. Aggregate diagnostic work separately without
altering benchmark/F/return counts or renewing the original pilot budget.

Bind exact new record/work primitive values and fixed scalar DTO container owners
through native callbacks and after the helper returns. Why this: ordinary Python
dictionary equality accepts bool/int retyping and equal replacement containers.
Keep original raw scores and private paid diagnostic prefix on refusal. Preserve
full native state/policy/54*point clocks/source/actor guards and omitted behavior.

## Alternatives

- A new runner duplicates existing budget, source and evidence guards.
- Three cue-pair diagnostics miss the native joint54-row update direction.
- Broad counter/metadata exceptions admit unobserved or corrupted state.
- Another full F/return study wastes accepted evidence when only TRAIN states
  need reconstructing for a new direction measurement.

## Consequences

Public opt-in behavior is verified by167 scripted/regression cases, two complete
native PC/neutral cases, statics and review. One separately frozen TRAIN-only PC
reconstruction exactly matches270 old probability rows and measures local descent
with nonzero residual, but does not prove why acquisition failed. Old scientific
SPENT/negative results and probability-vector gap are unchanged. A separately
named fixed finite-relaxation control is next; never tune or relabel the original
S2 baseline, claim equal computation or weaken bounded policy admission.
