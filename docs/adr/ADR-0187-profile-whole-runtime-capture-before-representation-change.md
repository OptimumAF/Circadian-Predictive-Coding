# ADR-0187: Profile whole runtime capture before changing representation

## Context

The full runtime observer has incomplete gates and most of its test budget spent.
Its actual complete captures are large; a smaller/sampled graph would lose proof
scope. Measure actual full object/path/native costs before optimizing.

## Decision

Run one separately declared full guarded V2/native/current-process cost diagnostic,
retain every instrumented member/full canonical body/all call rows and profile
limits. Measure one fixed lossless subtree transform on that complete body, prove
whole-byte independent readback/corruption denials and use identical inputs for
latency. Preserve every old60 source file, original closure and failed cap/receipt.

## Alternatives

No sampled module/function graph, skipped native/file reads, cached-away late drift,
outcome-based candidate selection or reset of j/scientific gates. Production encoder
integration would be premature without measured benefit and full new correctness.

parents/source-version/freshness/arrival/resource/repeat/helper criteria stay open.
