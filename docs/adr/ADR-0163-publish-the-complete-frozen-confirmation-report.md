# ADR-0163: Publish the complete frozen confirmation report

Status: accepted and implemented; complete actual publication/readback passed.
Date: 2026-10-01.

## Context

P6.7c supplies two complete identical scientific results. P6.11a predeclared
all ten-seed summaries and all 116 simultaneous primary statements. P6.11b1
binds all original costs; shared guard proof context makes its artifact 112 MB.
The original b acceptance requires complete seed/contrast/interval/cost evidence.

## Decision

Add six consumer modules, preserving the existing 100-source closure and all
scientific settings. Use both unchanged complete scored readers. Each gets a
fresh complete b1 readback, which independently reads both original training
bundles. Bind returned decoded bodies to exact input bytes and recheck all
source/request/input identities before and after composition/publication.

Reuse the unchanged pure analysis. Verify both entire payloads and both entire
analysis bodies are equal. Publish every 560 cell, 1,680 endpoint, 626 metric
vector/6,260 seed observation and 116 primary statement in deterministic JSON
and exhaustive Markdown. Keep every raw method cost, checkpoint capacity,
role, null/failure reason, negative value and interval eligibility status.
Bind all 60 shared contexts by exact original file/projection identity and
JSON pointer. This preserves full evidence without copying another proof body.

Exclusive request/result/Markdown/audit/failure/claim publication and independent
readback rederive every report byte. A failed failure-marker write revokes only
our still-identical completion audit. Source/input corruption and occupied
outputs fail before scientific input readers. Use a 180-second local derivative
validation budget; original scientific caps and resource observations remain
unchanged. Reports add no training or final-source access.

## Alternatives

- Choosing selected contrasts loses the predeclared multiple-comparison scope.
- Treating deterministic repeats as extra seeds changes the replication unit.
- Rounding/clipping report statistics hides raw interval or negative values.
- Copying full shared proof states duplicates 103 MB with no new cost evidence.
- Reimplementing analysis or complete input readers duplicates validated logic.

## Consequences

The report is large and exhaustive, with companion JSON for unabridged raw
fields and Markdown for all individual values and intervals. Each full consumer
operation performs four original complete training readbacks plus both scored
readbacks. Frozen 106-source/request records precede fabricated report fixtures.
New format/publication tests establish no actual scientific provenance. After
101 new/446 related tests passed, both actual full publications and both
independent complete readbacks exited 0 under each 180-second budget with all
24 source/model/train/final guards at zero. Both whole JSON and Markdown bodies
repeat byte for byte. The full report retains all 626 vectors/116 primary
statements, including eleven zero-dispersion primary CIs and two undefined
retention observations. No production source changed after its prospective
106-file freeze. `docs/p611-confirmation-report.md` records exact identities
and acceptance evidence. B2/b are checked; original matrix/resource/hypothesis/
reporting parents retain their own criteria and explicit next audits.
