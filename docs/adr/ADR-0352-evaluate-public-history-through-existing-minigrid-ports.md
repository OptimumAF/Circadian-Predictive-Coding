# ADR-0352: Evaluate public history through existing MiniGrid ports

## Context

The accepted feedforward public-history condition consumes296 values. The live
evaluator still admitted148 and sent only current observations. That blocked
target-free evaluation of the existing learners; native health and raw-fit
evidence did not establish live acquisition.

## Decision

Add an exact optional boolean to the existing evaluator. Transform admitted
original TRAIN packets for raw scoring and reset the existing causal encoder
from each live episode's public initial frame. Record actual296 decisions and
derived array costs. Keep recurrent148 sessions and default148 behavior intact.
Use the existing guarded training helper for original128 or explicit32 updates,
with exact tuples, original clocks, charges, receipts and completed-peer guards.
A fixed CLI trains all five arms before any readout and refuses altered prior
paid evidence using bounded copies of its five completed records.

## Alternatives

A separate trainer would duplicate state/budget logic. Reusing the original148
evaluator would discard the accepted public cue history. Another audit framework
would add no learner capability. These options do not address the port directly.

## Consequences

The296 condition can run real target-free episodes with bounded memory. Extra
inputs, copies, parameters and computation remain disclosed. A small engineering
case validates the boundary; acquisition needs its own frozen protocol. Original
failed live budgets and all negative scientific results remain unchanged.
