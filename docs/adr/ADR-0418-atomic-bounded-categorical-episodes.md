# ADR-0418: Publish bounded categorical episodes through the existing boundary

## Context

The detached bounded categorical kernel has accepted mathematical evidence.
A parameter-only assignment would omit native traffic, age, chemistry and legacy
history. Existing weighted episodes already provide a complete atomic boundary;
generic TrainingDiagnostic alone would discard bounded stopping and paid work.

## Decision

Share the original weighted native transition and donor/publication boundary
through private helpers. Add an explicit bounded complete-TRAIN PC/neutral API
returning owned scalar inference/work diagnostics. Fixed stage signatures,
policies, snapshot formats and defaults stay stable.

Why: both algorithms need the same complete native transition and atomic guard.
The new result preserves24core counters plus8adapter counters within the existing
32counter failure port. Only trusted numerical-core failures merge their work;
arbitrary later failures preserve known work and mark unknown. Stopping policy
is copied/validated before work and closing checks retain exact scalar types and
floating representations, so equal-valued replacements cannot pass unnoticed.

## Alternatives

Duplicating the entire boundary risks divergent donor and foreign-change checks.
Changing the generic native snapshot or default policy would mix explicit new
stopping choices with accepted fixed controls. Dropping richer results at the
array port would lose costs; scheduled binding remains a separate required step.

## Consequences

96scoped tests/statics and independent source+actual review accept the episode
API. It publishes one complete native update, including a charged update at the
prior after zeroaccepted safety fallback. Postproposal refusals retain work and
leave foreign changes in place. Administrative copies/admission/closing checks
are outside numerical counters; unexpected work remains explicitly unknown.

R1.5-T scheduled stream policy/work receipts and parent integration remain open.
No comparative or learning-benefit claim follows.
