# ADR-0398: Joint TRAIN-catalogue composition through existing native ports

## Context

Existing online native models have not acquired exact teacher traces. The fixed
linear one-hot least-squares control completes at52/54 actions and4/6 traces,
failing its all-label criterion. That does not prove inseparability or identify an
online failure cause. A distinct joint-exposure acquisition question is useful
before interpreting fresh-task learning, old-task retention and context return.

## Decision

Compose complete causal TRAIN sources into owned raw296/K7 array batches for the
existing training-only attribution stream and invariant native learner ports.
Keep current/action order, original source spans, unique exposure transport IDs,
separate repeated-row and logical-array costs, and a16MiB retained-input ceiling.
Validate current and next histories, including causal initial-frame consistency;
only current inputs and action labels reach training. Preserve native objectives,
matched method factories and all accepted sequential baselines.

Why this: the existing stream already owns label delay, candidate isolation,
receipts and budgets. Independent feedforward rows need a data composition
boundary, not another runner or a fictitious joined demonstration episode.

## Alternatives

- Add a new orchestration framework: duplicates working runtime boundaries.
- Relabel joint exposure as an equal-compute online baseline: scientifically
  invalid; a54-row wake differs from the original9-row exposure.
- Change solver, thresholds or selected data after the negative fit: changes the
  completed question and would not establish useful native acquisition.

## Consequences

The composer is bounded and environment-free. Recurrent/episode replay semantics
are outside this independent-row path. Full runtime copies and native work still
need their own memory and computation accounting. Current79 scoped cases include
four real native heads completing two joint updates each, without modifying source
or actor. Correct operation does not demonstrate learning benefit.

Before a scientific joint acquisition assay, narrowly extend the existing fixed
nine-row checkpoint admission with explicit bounded expected native-row evidence;
retain its default and complete state checks. Reuse existing F/old-A/A-return
probes, freeze the protocol, and preserve all previous SPENT grants/negative runs.
