# ADR-0184: Share whole-file proofs for versioned generation bundles

## Context

The completed V1 reader validates concrete-role file metadata; g adds the proper
V2 generation representation with unset development IDs and frozen assignment
recipes. Both need identical physical path/publication/alias/canonical/whole-byte/
code-membership/recheck rules. IO must remain outside app/core and neither format
can be promoted to runtime closure/live ownership/actual chronology or admission.

## Decision

Add V2 immutable snapshot/result and inner reader protocol, pure exact decoder/
complete g preflight and outer V2 reader. Extract V1's identical physical policy
into `src/infra/prospective_bundle_files.py`; delegate both typed adapters to it.
Prospectively permit only the V1 infra implementation edit, preserve its entire
earlier bytes, public constructor/read/recheck signatures and behavior, and run
all55 older V1 cases in the full388 related suite. The shared helpers/read/recheck
bodies exactly specialize to the preserved V1 AST. Direct source-map recheck
compares the supplied snapshot, preserving strict numeric types. Two actual
regressions exposed the rebuilt-snapshot comparison and verify the restoration.

Why this: sharing real duplicated IO rules reduces version drift while full
versioned schemas and scientific recipe validation remain separate. Reuse the
immutable expected-file spec and closed-code manifest decoder. The edited prior
reader is absent from the original150-source closure, which remains unrekeyed;
all42 other prior lead files and all parent criteria remain unchanged.

## Alternatives

Duplicate the V1 physical code for V2: two evolving path/recheck policies. Feed V2
through V1 after fabricating concrete development IDs: source-related work is too
early and violates frozen recipe representation. Change the original V1 schema:
breaks users and accepted evidence. Claim UTC/owner/manifest declarations prove
actual chronology/lease/runtime closure: no observing trusted proof. None adopted.

## Consequences

V2 full physical metadata is testable under raising scientific guards with IO
allowed. Full480 recipes/100 sources/400 streams/60 bindings, unchanged design/
resource/repeat and all12 actual-proof obligations remain bound. No source/RNG/
array/science/seed choice, dependency or settings/metrics/baseline change. Complete
runtime closure/live owner/sequential arrival/assignment/chronology/unrecycled
independence/prior effects/failed resource/repeat/b3 gates remain necessary.
Independence unknown; fresh/execution/precision authority false. Only h may be
checked after behavioral/static and whole-preservation/terminal gates; parents open.
