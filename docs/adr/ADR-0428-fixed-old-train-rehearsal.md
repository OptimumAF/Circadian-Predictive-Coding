# ADR0428: explicit fixed historical TRAIN episodes in existing rehearsal

## Context

The existing rehearsal helper retains newly completed wake episodes. A useful
old-A control during new-task learning needs an explicit historical TRAIN bank.
Fabricated wake receipts or private-buffer prefill would obscure exposures and
budget authority. The preserved representation experiment gave no advantage;
old-task acquisition remains unqualified.

## Decision

Add an opt-in complete fixed TRAIN tuple to `StreamRehearsal`. Validate the whole
bank before insertion, require the entire bank fits retention and each event,
and leave incoming wake validation active without replacing the bank. Reuse
existing content IDs and owned continuation; no new digest or history framework.
Keep original replay budget charges and candidate consolidation unchanged.

Compose public raw296/K7 A episodes through a small adapter factory using the
existing catalogue causal validator and original invariant native recipe.
Expose validation projection costs and existing encoded payload accounting.
No reserved-role conversion, new stream runner or new scientific comparison.

## Alternatives

Arrived-only FIFO can evict old A. Context coverage changes selection semantics
and also lacks explicit historical admission. New orchestration would duplicate
the existing stream's receipt, isolation and budget responsibilities.

## Consequences

Existing defaults remain unchanged. The new control pays extra replay exposure
and native work; any later comparison must match/report those costs. Logical
payload excludes copies, metadata and event/native state; process RSS remains
additional. Supplied valid TRAIN metadata authenticates no historical acquisition
or frozen study membership. Full probe integration, matched science, acquired
retention/recovery and release claims remain open.
