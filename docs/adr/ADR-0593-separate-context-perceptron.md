## Decision

More replay sweeps do not isolate the observed tradeoff. A new optimizer or CPC
mechanism is unnecessary to test this conventional stronger control. Shared
context features alone still share coefficients/bias. A new stream or serialization
framework duplicates existing ownership and budget behavior.
