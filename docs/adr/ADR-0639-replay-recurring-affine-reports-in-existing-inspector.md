# ADR-0639: replay recurring affine reports through the shared inspector

Status: accepted for scoped recorded presentation; no scientific/release claim.

## Context

The installed ordinary recurring command now produces ten-update A/B/C/G/A
learning and successful known G/A traces. The existing affine inspector only
accepts the older six-update ABC report. A usable fresh run also needs recorded
trajectory playback. Repeating the model experiment would add no presentation
evidence.

## Decision

Use two explicit fixed recipe records in the existing affine projector. Shared
TRAIN, cost and native-frame helpers retain the original normal defaults used
by the private projector. The exact recurring definition selects only its own
points, row counts, source slots, layouts and roles. Validate original teacher
collection, arrived-only bounded banks and original workflow/phase clocks;
present plans separately from committed receipts and partial paid work.

Reuse the existing shared dispatcher and HTML template. The recurring view adds
stage labels and original workflow/teacher costs. Every observed value/frame
keeps its saved pointer. Missing observations never gain invented outcomes or
source records. No learner, simulator, numerical operation or saved-weight
restoration belongs in the projection.

## Alternatives

A separate inspector would duplicate native decoding, frame playback and source
dialogs. Broadly accepting arbitrary counters/layouts would silently relax fixed
scientific formats. Importing runtime recipe builders would make the inward
application layer depend on scripts and risk native/data work during playback.

## Consequences and evidence

Normal and private rules/projection shape stay unchanged. Recurring reports add
a mode marker consumed by the existing template. Literal fixtures establish
validation behavior, not learned outcomes.92distinct focused checks qualify per
platform; scoped lint/format/fresh types pass. One saved127public-CLI export
preserves its source and exact48curves/10receipts/4native traces/171cost pointers;
desktop/narrow browser checks and screenshots pass. All work is saved-only.
Source/procedure/result review is self-review, not independent acceptance.

The viewer does not authenticate external history or establish reliable learning,
recovery from forgetting, heldout transfer, matched compute or a CPC advantage.
Full recurrent-RL/scientific/release parents remain open. Original native failures
and A/C confidence regressions remain. Keep future fixed formats explicit and
test changed boundaries before adding another rendering path.
