# ADR-0508: fixed weights through existing mixed continuation

## Context

Native positive row-weighted BC is qualified, but the existing recorded mixed
continuation only calls two-argument training and cannot retain weighted objective
provenance. A prefix/group-aware148-row repair requires that concrete integration.
Accepted mean correction fit improves while first-action/expert fit worsens; all
physical failures remain and weights have no demonstrated benefit yet.

## Decision

Add optional fixed weights only to explicit mixed continuation. Validate/copy the
whole positive vector before forks, preserving row bindings/order and all real
exposure. Use existing ActorShadowRuntime and RecordedContinuousMixed: own forked
configuration, record exact raw weights with weighted diagnostic IDs in bounded
successful receipts, retain the one latest model pin and paid failures, and refuse
weight/evidence mutation before more work. Keep default schema and calls unchanged.
Store raw values/masses once in continuation metadata; count actual row exposure
and receipt weight payload separately. Selected native mass-admission calls are
source-derived; additional validation/arithmetic/copy costs remain explicit.

## Alternatives

- Modify shared runtime ports to carry weights: unnecessary for a fixed batch.
- Duplicate/drop observations: changes exposure or discards evidence.
- Start an unrecorded weighted study directly: loses exact supervision provenance
  and failure accounting at the existing runtime boundary.

## Consequences

One explicit optional argument and bounded receipt extension, no dependency,
optimizer or runner. Qualify real native updates/default equivalence/ownership/
roles/paid failures first. Then freeze one small learning study separately; no
physical, comparative CPC or release claim from implementation correctness.
