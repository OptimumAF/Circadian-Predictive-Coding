# ADR-0319: Compose capacity cohorts with bounded prune evidence

## Context

The roadmap requires a measured split/prune, growth, equal-final-width and
renewal comparison. Existing learner/runtime mathematics and owned states work,
including matched structural BP and renewal/capacity composition. The remaining
gap is the full recipe and one observed-damage pruning boundary. Existing prune
consolidation discards successful per-probe evidence needed to report gate work.

## Decision

Compose all cohorts through the existing attribution stream. Add one explicit
prune schedule with owned validation policy/data and bounded scalar diagnostics.
Keep rejected unchanged candidates training; stop failed/unknown work. Preserve
runtime receipts, original charges/budgets and wake-weighted capacity means.
Add optional bounded owned last-decision retention after evidence validation,
defaulting off and clearing before every call, without rerunning any gate.

Keep raw structural and ordinary renewal cohorts separate. Use both fixed
possible final-width references, preserving the width3 reference's non-isometric
initialization. Freeze data, thresholds, policies, comparison directions and
resource limits before any comparative outcome, including rejected/zero results.

## Alternatives

- New pruning math or arbitrary transformation frameworks duplicate validated
  kernels and widen the trusted boundary without a demonstrated need.
- Repeating a gate to recover discarded evidence changes computation and can
  produce a different result; retain its one actual validated decision instead.
- Treating equal stored width as equal computation or fitting initial scores
  would weaken the scientific comparison.

## Consequences

The existing CLI can deliver every required mechanism and its cost/outcome
records in one bounded local recipe. This does not establish general learning
benefit, biological reconstruction, equal compute or a circadian advantage.
Further protocol changes need prospective review; all negative results remain.
