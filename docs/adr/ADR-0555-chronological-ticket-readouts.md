# ADR-0555 — Observe complete ticket tasks between fixed TRAIN phases

## Context

The conventional full ticket driver fits all concepts before effects. Existing
native drivers also fit before all episodes; the CLM observer tooling increment
is deferred after failed fixtures. Existing R2.1/robotics/game/replay results are
already extensive and should not be rebuilt to avoid this failure.

## Decision

Compose the unchanged perceptron, delayed AttributionStream and effect dispatcher
with fixed invoice→parcel→invoice TRAIN and both-task readouts0/4/8/12. Use one
original12-update budget/candidate. Freeze snapshots for readouts and verify
candidate/budget conservation. Keep signed new-task gain, old-task forgetting and
return change, all raw outcomes and costs; a negative result is valid.

Why this: it demonstrates chronological full-task acquisition/retention/return
using existing working components instead of another observer/capture increment.
It is a separate useful outcome, not a renamed native scientific retry.

## Alternatives and consequences

Native observer tooling remains unfinished with its failures/budgets intact.
Repeating the old all-concepts baseline or extending probe horizons adds less
information. No new algorithm/controller/framework, source restoration, actor
promotion or final/probe access. Shadow candidate snapshots, not the seed owner,
represent trained state. The simple overlapping repeated tasks do not establish
generalization, four-family superiority, CPC benefit or continuous deployment.
