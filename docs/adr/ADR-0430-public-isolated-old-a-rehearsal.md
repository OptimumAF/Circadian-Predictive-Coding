# ADR0430: expose isolated old-A rehearsal through the existing MiniGrid CLI

## Context

The accepted fresh-task API can compose the existing stream and fixed TRAIN bank,
but the public MiniGrid pilot could not select it or report its additional work.
Original scientific controls have not acquired old A; correctness is separate
from a future comparative result.

## Decision

Expose an explicit `--old-a-rehearsal` option only for the original invariant
native joint128/F16/old-A/A16 recipe. Reuse the existing disposable candidate,
stream and same-candidate return. Create and bind a separate replay budget before
the factory; protect event-backed charges and preceding public evidence.

Report attempted/returned/committed replay calls, charged and returned rows,
logical bank admissions and validation/native projection costs separately.
Preserve missing evidence as unknown and partial numeric sums as lower bounds.
Keep disabled call shapes/reports and frozen objectives unchanged.

Why this: a small option/description/cost helper and existing orchestration are
sufficient. Another runner or provenance system would duplicate accepted behavior.

## Alternatives

Making replay implicit changes baseline exposure. Combining its charge with F
conceals additional work. Admitting every encoding/objective would promise
unverified combinations. Treating synthetic integration output as scientific
evidence would overstate this increment.

## Consequences

The public route runs and reports its costs; separate matched scientific protocol,
exact study cohort binding and acquisition/retention/recovery claims remain open.
No final data enter updates or selection. Original negative/incomplete runs and
full repository/release requirements remain preserved.
