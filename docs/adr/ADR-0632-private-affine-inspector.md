# ADR-0632: display private affine evidence in the shared inspector

Status: accepted scoped implementation decision; broader scientific/release criteria stay open.

Context: the first-party private comparison produces useful learning and cost
evidence, including a failed native readout. The normal affine inspector rejects
its definition and assumes one TRAIN-only native phase. Relabeling the private
report would lose role, clock and incomplete-control distinctions.

Decision: add one pure app projection for the explicit private definition. Reuse
the original TRAIN validator, native episode decoder, file bounds and shared HTML.
Keep three visible conditions: frozen reference, F-only control and joint ABC/F.
Separate fit/native status; retain exact pointers, nulls, omitted values, permanent
attempts and failed/unrun slots. A small new app module avoids doubling the normal
projector while preserving its public behavior.

Alternatives: another dashboard duplicates native playback and export; cloning a
normal-schema input invents evidence; rerunning missing games would violate the
spent native protocol. None is required to explain the existing data.

Consequences: no model, simulation, training, promotion or source authentication
occurs. Old accuracy derives only from saved correct counts; original CE and
confidence tradeoffs stay visible. Recorded phase costs cannot become external
whole-process costs. Viewer completion cannot close the unfinished native case
or broad adaptation, CPC, generalization and release claims. Validation is scoped
software/export/browser evidence and self-review, not independent acceptance.
