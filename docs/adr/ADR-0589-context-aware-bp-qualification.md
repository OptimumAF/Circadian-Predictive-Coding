# ADR-0589: Qualify the contextual conventional learner before adaptation claims

## Context

The public context path removes a known D7 label alias, but its deterministic
TRAIN-table control is not a learned policy. The original BP qualifier already
owns a fixed joint TRAIN stream and protected actual task readouts.

## Decision

Add one explicit mode to that qualifier: D9/H3/K6, fixed seed17/optimizer,
v1invoice/password and v2invoice/parcel available jointly,96full12row updates and
endpoints0/96. Validate exact context TRAIN groups/schema/public alignment/no
contradictory inputs, then reuse full native BP, existing stream and sandbox.
Keep the default D7 recipe and source authority unchanged. Protect original
inputs and paid initial evidence before more work; preserve failures and costs.

Why this: the conventional learner must demonstrate actual task ability after
the observation repair before making further retention, recovery or CPC claims.

## Alternatives and consequences

No new runner, source migration, optimizer, capacity mechanism or final data.
Joint data is not a chronological continual-learning demonstration. Changing D9
geometry/data/initial tensors/row exposure means no causal or matched-compute
comparison with the earlier D7 qualification. A negative result is valid.

The sole case completes96SGD/1152rows, fits10/12 but still routes both v1invoice
and v2parcel to inspect. Password/v2invoice ordinary and stale workflows pass;
all final revoked commits are denied. Joint four-task qualification therefore
remains unsuccessful. Preserve all outcomes; do not increase dose or select a
seed to manufacture success. Next test the existing simpler perceptron under a
separate fixed protocol, sharing pure joint teacher selection through the teacher
module rather than making circular script imports.

21focused checks/platform, scoped statics and executed source/counter/effect
readback pass; this is self-review, not independent/scientific/release acceptance.
