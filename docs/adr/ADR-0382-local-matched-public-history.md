# ADR-0382: bounded public history for matched local learners

## Context

The local8-coordinate A branch observation can alias two earlier public cues
requiring different actions. Existing feature learners admit16 inputs; the
existing official MiniGrid history module specifies148→296 and cannot silently
be repurposed. Previous quota E probes show incomplete supervised fit and do not
establish useful adaptation or circadian benefit.

## Decision

Use a pure exact8→16 initial-plus-current transform for local episode records,
with reset before replacement validation. Compose the existing four feature
learners and AttributionStream in one fixed opt-in TRAIN-only CLI recipe.
Keep all original method configurations, data, seed, schedule and parameter
initialization matched. Retain exact PC-neutral parity checks and original
runtime/receipt/budget guards. Score TRAIN checkpoints only after all streams
finish. Preserve stopped-owner refusal and observed preceding-success evidence
when a later native update fails.

## Alternatives

Changing default observations would invalidate accepted baseline assumptions.
Adding hidden context/labels would provide unavailable information. A recurrent
replacement or another orchestration framework is unnecessary for this bounded
observability prerequisite. Extending the official MiniGrid contract would mix
different public observation schemas.

## Consequences

The demonstrated A cue pair becomes distinguishable using public information.
Input storage and parameter counts increase equally across four methods; native
objectives and computation still differ. Hidden B mapping remains unresolved.
No final/live/probe data are constructed. The executed eight-update case has
zero exact TRAIN sequences at all checkpoints; useful acquisition, retention,
recovery, generalization and comparative advantage remain unestablished.
See the frozen protocol and executed evidence in
`artifacts/runs/matched-public-history-20261017/`.

## Reserved-capacity extension

The explicit history-probe scenario reuses the same four learners, full owned
native0/end8 checkpoints and existing checkpoint/fresh-task probe helpers.
The benchmark stream and all TRAIN readouts finish before reserved collection.
Each of eight E16 probes uses a separate budget and disposable native state;
pure checks preserve benchmark state/bindings and prior probe evidence.
Only the current private helper slot may be published; previously published
values and identities remain checked. The original TRAIN-only scenario remains
unchanged. This avoids an unnecessary new bridge or runner. Costs are additional,
and deterministic reserved fit does not establish useful old-task recovery or
generalization. See `artifacts/runs/matched-history-probes-20261017/`.
