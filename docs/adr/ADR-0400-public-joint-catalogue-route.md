# ADR-0400: Compose joint acquisition through the existing MiniGrid route

## Context

The tested catalogue composer and explicit54-row checkpoint/probe binding lacked
a public runnable path. The existing support reducer admitted128 complete episode
packets, while joint independent-row transport deliberately has `episode=None`.
The first actual public integration exposed that dependency after128 paid updates.

## Decision

Add one strict opt-in route composition module and API/CLI flag. Reuse original
native methods, source collection, causal encoding, training-only stream,
checkpoints and disposable F/old-A/A-return orchestration. All54 TRAIN rows enter
each wake; report exposure and array costs explicitly. Require one bound method
and the complete isolated-probe options; refuse unsupported combinations early.
Preserve the omitted flag's original behavior.

Support admission gains an explicit exact-bool six-source mode requiring the
original complete ordered A/B/C_train blue/red raw episodes. Analyze that set once
plus the unchanged18 F packets,216 projections total. Why this: repeated exposure
does not change the support set, and source witnesses/private guards already bind
every joint wake to these sources. Never accept arbitrary replacement metadata,
fake a continuous trajectory, relax default128-packet admission or drop exposures.

## Alternatives

- A new runner duplicates delayed-label, state and budget logic.
- Joining episodes creates a false sequence and corrupts provenance.
- Suppressing counter/support checks loses the explicit54-row and novelty law.
- Calling joint training matched online exposure hides a sixfold row-dose change.

## Consequences

This delivers runnable acquisition and isolated-adaptation measurement, not useful
acquired skill. One frozen four-method study is runtime complete and negative for
full acquisition; reported PC/neutral metrics match with no active benefit.
Protocol probability-recomputation evidence is partial because probe DTOs do not
persist probabilities. Keep that criterion open and all cases SPENT. Existing
legacy squared PC energy remains a diagnostic (ADR0021); neither it nor the
learning law is relabeled or tuned here. Full R2.1/release requirements stay open.
