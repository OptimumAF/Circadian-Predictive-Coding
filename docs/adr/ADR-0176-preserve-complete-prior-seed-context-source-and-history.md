# ADR-0176: preserve complete prior seed context, source and history

## Context

B1 inventories retained JSON seed-named declarations. Its null policies,
record containers and quantities need schema context. Structured seed_map
streams, JSONL, source/default expressions, text/CSV and historical code can
contain additional provenance. Original b2 requires complete usage and release
evidence before fresh roles. Historical missing producers remain unknown.

## Decision

Add b2a as a complete evidence boundary over all retained physical checkout
files and local Git objects with full reachable commit/path aliases. Keep every
b1 declaration/issue, structured map, source/text/CSV/JSONL record and opaque/
unparsed/symbolic case. Bind full identities and membership before/after, parse
exact duplicate bytes once with every alias retained, and execute no source,
RNG, model or checkpoint contents. No new dependency or scientific gate change.

Why this: names and literal values alone do not establish seed semantics or
past role exposure. Preserved snapshots and failed producers are evidence.
Deduplicating whole identical bytes reduces raw memory without narrowing scope
or counting copies as independent trials. Unknown use remains unknown.

## Alternatives

- Filter unresolved declarations by suffix alone: can discard policy, history
  and stream evidence or relabel quantities as RNG identities.
- Audit representative source files/commits: misses retained defaults/copies.
- Execute old scripts or unpickle state to discover seeds: unnecessarily opens
  scientific/model contents and risks changing state before fresh-role gates.
- Declare fresh roles from numeric JSON values alone: missing full history.

## Consequences

B2a can complete its evidence boundary while complete prior-usage and fresh-role
authority remain false. Original b2/d2b/d2/P6.7 criteria remain unchanged and
open. B2 must resolve/constrain remaining uncertainty and actual release history,
then bind the fixed independent role/config/count/resource/analysis contract;
b3 must pass full execution fixtures before d3. See the complete evidence guide.
