# ADR-0427: Reuse isolated F and A-return probes for the cue-relative family

## Context

The cue-relative codec and native family are accepted. The constructive TRAIN
route executes it, but its fixed128scientific result remains48/54/0exact. The
existing learnability pilot already implements independent F16 adaptation,
old-A monitoring and A16 return. Its factory, counters and strict snapshot paths
previously recognized only the old families.

## Decision

Add an explicit `cue_relative_history` selection to the existing joint public
route and CLI. Register all four new native methods in existing factory,
checkpoint/counter and receipt paths. A small adapter helper owns the fixed
recipe, exact complete snapshots, full raw causal admission and protocol metadata.
Keep raw transport and one learner projection. Reuse existing source/actor,
original budget/clock, immutable evidence and permanent-charge guards.

Require the complete joint/F/old-A/return recipe and refuse incompatible old
diagnostics, weighting and rollouts. Keep original default behavior and native
math. Relabel all method-indexed storage maps explicitly. Admit the complete
cue/key domain before inferring new-input support equality from the old canonical
tables; retain their original measured-work labels.

## Alternatives

A second probe runner would duplicate tested isolation/accounting. Treating new
snapshots as generic records would bypass explicit policy/clock checks. Feeding
pre-projected arrays into a bound learner would undo red-cue remapping. Silently
using old diagnostic readers would compute inconsistent representations.

## Consequences

All four methods execute the existing F/A-return probes, and the public BP route
is runnable with new bounds and unchanged source/actor state.254scoped cases and
scoped static checks pass. A synthetic novelty fixture refusal remains preserved;
its public-only correction and cap revision were reviewed prospectively. No
scientific model run was issued for this increment, and no acquisition, retention,
recovery or CPC advantage follows from integration correctness. Full research
and release requirements remain open.
