## Context

Issue106 demonstrates known-A games from an offline joint fit. Neither proves
that the causal current-task policies execute complete native tasks.

## Decision

Add a narrow exact snapshot binding to the existing evaluator. Restore genuine
states2/4/6 into independent scorer forks of an untrained owner; preserve the

Keep detached preceding complete phase reports and validate them before more
work. On failure preserve that known prefix and any current paid report; stop

or source-admission framework is unnecessary; ordinary typed conversion suffices.

CPC benefit. Preserve107TRAINforgetting and later measure retention with honest
