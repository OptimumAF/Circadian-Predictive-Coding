# ADR-0189: Validate whole runtime records without provenance authority

## Context

Outer keys/hash equality accepted foreign nested content. Full actual offline
probe passed63 controls; active full547 then failed3 because literal_eval compiles
text under the required audit. Complete before/after observations exposed additional
first-use/error-frame marshal changes. All failures/versions/caps remain preserved.

## Decision

Five focused pure core modules check every encoded record/child/identity/order/
alias/representable join. App validates exact current/prior full scope/header/
continuity and reader/runtime final checks for every pre-yield/consumer/error path.
Use native passive string escape decoding plus exact canonical repr round-trip;
fixed patterns/failure detail references load before freeze. Keep full native code
bytes/audit/GC/files/memory coverage unchanged. Registry lives for one validation.

## Alternatives

Literal parsing/audit exemption, invented small positive descriptors, graph sampling,
code normalization and a fabricated closed semantic type catalog weaken the required
proof or reject legitimate opaque names. None is accepted.

## Consequences

Malformed content is rejected with a correctly recomputed whole hash; complete
current548 regression and597-file static checks pass after the separate static
callback correction. Original400s/500s/output gates remain failed and unchecked.
Source-version/marshal-refcount/transient/native correspondence/nested route/omitted
unreferenced membership/arrival/prior/ledger/all b3 gates remain explicit obligations.
Historical records and shape confer no source/freshness/precision/execution authority.
No new dependency/config/type suppression or original source closure rekey.
