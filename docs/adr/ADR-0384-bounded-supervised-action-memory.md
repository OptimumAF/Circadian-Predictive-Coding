# ADR-0384: bounded supervised public-observation action memory

## Context

Matched BP/PC/neutral CPC/active CPC controls with public initial/current frames
failed all known TRAIN live readouts after the fixed eight updates. A test-only
lookup demonstrated sufficient information for this fixed demonstration. The
next useful increment is a real simple learner, rather than another audit mode.

## Decision

Add a pure exact public16→five-count model and owned NativeLearner adapter.
Fix64keys/10752 logical bytes, empirical conflict distributions, unseen uniform
five and atomic cap refusal prospectively. Use a separate observation_memory
identity and compose existing AttributionStream/history/live episode helpers in
a small concrete recipe. Inject existing backend-neutral full-state comparison
only on this route; preserve neural comparator defaults. Label storage work
explicitly, with N/A parameter/parity flags and measured overhead.

## Alternatives

Retuning neural dose, changing seeds or adding circadian mechanisms would not
answer whether the existing observations support useful simple acquisition.
A nearest-neighbor model, eviction policy or context-ID table adds unreviewed
behavior. A generic backend runner refactor broadens the change unnecessarily.

## Consequences

Known TRAIN recall, retention and returning-context behavior become measurable
with real physics and exact table provenance. This is unequal-capacity supervised
memorization, not generalization or a circadian advantage. Capacity exhaustion
fails explicitly; expansion requires a new justified protocol. No new dependency,
final-data access, probe tuning, replay or serving promotion is introduced.

## Isolated capacity extension

Use an opt-in E16 mode in the same recipe, composing the existing checkpoint and
fresh-task helpers. It runs authentic0/end8 benchmark snapshots and separate
16-update disposable copies after TRAIN scores. Reuse accepted known-TRAIN live
results rather than repeat live episodes in this assay. Preserve capacity/miss/
conflict laws; count refusal is a valid negative. Report derived table growth
separately from observed native snapshots/whole-process RSS. No new orchestration
framework, learner algorithm, dependency, budget renewal or final-data access.

## Explicit MiniGrid geometry extension

The existing MiniGrid public-history encoder produces296 features and seven
actions, while this control alone was fixed16/5. Admit only those two exact
geometries in the same core/native port; no new learner or orchestration layer.
Bind entry shapes to snapshot policy and compute logical payload from declared
dimensions. Preserve every old default, including the10752B allowance and168B
legacy constant. MiniGrid's2424B/key requires an explicit155136B request to use
all64keys; dimensions alone cannot silently enlarge the payload budget.

Why: this closes a concrete input capability gap while keeping old accepted
cases and their scientific evidence intact. Generalizing arbitrary dimensions,
adding eviction or modifying old experiment capacity would broaden the question.
Engineering stream fixtures verify composition; actual MiniGrid adaptation and
comparison require a distinct prospectively frozen local protocol.

## MiniGrid native readout composition

Add the fixed observation_memory control through the existing MiniGrid collector,
training arm and evaluator. Keep original128-update A/B/C/A dose/seed17, public
initial/current representation and raw action rules. Admit only the exact296/7/
64-key/155136B checkpoint and original six TRAIN sources/layouts; no final/probe
extension. Select backend-neutral full-state comparison only for memory; preserve
all neural defaults. Retain known committed receipts before fallible current-model
readback, with unknown current state explicit, and recheck source/actor after a
terminal candidate callback. Keep only five immutable private readout payloads.

This uses existing ports rather than a new framework. Different table capacity,
storage updates and work costs prevent an equal-compute or neural-benefit claim.

## MiniGrid saved-state reserved capacity

Compose the existing reserved collector/public-history/fresh-task helper on owned
initial0/end128 snapshots from the accepted saved live report. Restore through
ordinary bounded JSON and existing typed records; do not rerun128benchmark updates
or add a codec/source-admission system. Retain one helper-created disposable fork
per cohort to report its actual end table and clocks. Original16-update budgets,
64-key/155136B cap, fixed E roles/seed/checkpoints and failed prefixes stay intact.

Why: known-task recall does not answer whether mature memory can admit a new task.
A mature cap refusal is informative; increasing capacity or inventing an endpoint
would answer a different question. Validate raw roles before metadata conversion,
and preserve raw session observations separately from verified charge lower bounds
when original bindings/native readback are damaged. No learner/helper/default
algorithm change, final access, live probe, selection or benchmark contamination.
