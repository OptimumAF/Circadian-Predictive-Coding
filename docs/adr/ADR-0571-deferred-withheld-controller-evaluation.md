# ADR-0571 — Defer task evaluation until a frozen controller cohort completes

## Context

The trained table equals drift0.1 on original six-row feedback. R7.5 needs
different receipt/error/recurrence conditions with fixed policies and independent
outcome measurement. The existing native schedule assumed delay1 and included
development task readouts/guards inside each case.

## Decision

Add bounded declared twelve-row recurring/diluted and noisy TRAIN recipes from
existing teacher packets. Preserve source buffers and mark the exact known
invoice target corruption. Derive readiness from arrived labels and retain the
original FIFO/native admission over a full n+delay horizon.

Add explicit deferred mode to the existing native case and a finite comparison
recipe behind its CLI. Candidate work completes without workflow task readouts
or promotion; failed/unknown predecessors close further work. Freeze all10cases
before opening the existing detached readonly final task source. Keep original
fit/reference parameters and input byte identity; no new controller fit or source
loader framework. Existing live/outer/learned modes and budgets stay authoritative.

## Alternatives

Repeating six-row traces cannot distinguish the policies. Adapting a threshold
or changing targets after results would tune the comparison. Exposing final task
outcomes inside scheduling/guard selection would violate isolation. Assigning
all historical fitting overhead to zero would conceal known discarded work;
inventing its precise allocation from an aggregate report is also unsupported.

## Consequences

Policy choices can differ under real native TRAIN receipt shifts while external
task scoring stays closed until every candidate is frozen. Incremental utility
and work are reported; exact all-in fit overhead remains unavailable. Shared
grammar and one small fixed study support only bounded schedule robustness
findings. There is no matched-compute, novel-task, deployment or CPC claim.
Platform momentum buffers can differ at float32 precision; original producer
environment is retained rather than broadening an equality gate. Self-review
is not independent acceptance.
