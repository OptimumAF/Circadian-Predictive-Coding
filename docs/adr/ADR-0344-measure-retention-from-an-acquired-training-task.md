# ADR-0344: Measure retention from an acquired training task

## Context

The original A64 initial phase and equal-exposure A128 control leave A partially
acquired. A loss/return measured from these conditions cannot establish restoration
of a fully acquired skill. The accepted A64/B64/A64 endpoint fits both A sequences,
but matching-law operational acquisition still needs actual verification.

## Decision

Continue the unchanged192 prefix with declared C_train64/A64 in the existing
stream. After all320 fixed updates, evaluate owned192/256/320 A/C states under
the same legal law. Require both initial A teacher sequences and both initial
live successes for a descriptive retention interpretation; otherwise retain an
inconclusive result without changing the training schedule or budget.

Reuse existing native mathematics, stream, evaluator and receipt/state authority.
Keep twelve fixed slots and a bounded completed-result seal; publish derived
acquisition after the final helper guard and refuse later caller-hook mutation.
Core arithmetic validates exact endpoints and preserves five fixed signed metrics.

## Alternatives

Another dose search does not address the initial-acquisition condition. Comparing
different live action laws confounds behavior. A new runner duplicates existing
authority. A192 equal-total-native control is still needed for causal B-history
attribution, but is not required for this descriptive retention/relearning study.

## Consequences

Prefix regeneration is necessary because old JSON lacks native continuation
tensors; exact score/decision/receipt parity is evidence, not a reconstructed
tensor identity. All exposures/diagnostic work are counted. C_train remains a
training context, no held-out or circadian advantage follows, and failures stay.

## Follow-up: existing matched replay composition

The executed no-replay case learned C and relearned A but lost the other context
at each switch. Compose the existing recent48 and coverage policies in this same
stream to investigate retention, keeping their update schedules and payload caps
matched. Preserve explicit wake/native counters and independently establish A192
and C256 acquisition per arm; replay changes the prefix, so common starting
weights cannot be assumed. Metadata and recent-parity differences are disclosed.
This is a training-domain comparison, not a new algorithm, a dose search, or a
claim of generalization. No-replay remains an unequal-compute reference.
