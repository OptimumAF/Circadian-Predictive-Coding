# ADR-0480: Condition teaching phases on geometry

## Context

The existing fixed teacher advances to grasp/lift after fixed call counts.
Corrective labels are collected on a student's different trajectory. Eight
private neural updates gave nine native zero-success episodes in the latest
three completed arms; fixed RGB-range repair also had negative native results.
Those observations do not identify a sole failure cause, but the time-based
teacher has no geometric readiness requirement at off-reference states.

## Decision

Keep the original fixed teacher/provenance intact. Add an explicit geometry-
readiness teacher in core, using current TCP/cube/goal positions, the existing
root controller and at most50decisions. Bounded scalar state counts six close
commands and recovers approach after loss of proximity. Reuse the existing
collector/CLI through a separate TRAIN17/19 wrapper, distinct definition and IDs.
Default signatures/CLI JSON remain unchanged. New state qualification requires
native42D or the fixed789D RGB recipe; fake fixture convenience cannot broaden it.

## Alternatives

More epochs, a new circadian mechanism or a repeat of the normalization study
would leave this teaching-signal uncertainty unresolved. Replacing original
provenance would invalidate accepted data. A second native runner would duplicate
existing geometry/controller/reward/cleanup accounting.

## Consequences

A focused qualification can now test this conventional teacher before its labels
are used for learning. Geometry proximity and close commands cannot prove contact,
attachment, safety or recovery from arbitrary states. New corrective labels need
a distinct schema and independently qualified behavior; old fixed batches cannot
be relabeled. Native usefulness, neural acquisition and comparative benefit are
separate from core correctness. All negative results remain preserved.
