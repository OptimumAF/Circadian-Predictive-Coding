# ADR0431: reuse qualified saved controls for the old-A rehearsal comparison

## Context

The original four-method joint/F/A-return study is complete and negative for
acquisition. The public fixed old-A replay route is accepted. Repeating baseline
training adds cost without resolving a new implementation requirement.

## Decision

Add a pure saved-report comparison and a small JSON CLI. Qualify exact original
cohort/recipe/benchmark anchors, correct phase episode roles/identities, full
selected replay episodes, paid work and all reported curves before describing
differences. Reuse original no-replay reports; execute each predeclared new replay
method once only after protocol/source gates. Preserve all failures and refusals.

Why this: existing pilot outputs already contain the required cohort, TRAIN
probability, probe decision/loss and cost evidence. No new training framework,
hash system or reconstruction of the historical archive is required.

## Alternatives

Rerunning controls spends computation without changing the scientific question.
Comparing only summary endpoints ignores mismatched sources or partial work.
Treating extra old-A replay as equal compute/exposure would misstate the design.

## Consequences

The public tool can explain F fit, old-A interference/return and additional costs.
Missing probe probability vectors limit independent score verification. Existing
old-A acquisition failures prevent acquired-retention/recovery claims. Matching
intervention compute/exposure, robust learning benefit and release readiness
remain separate unfinished requirements.
