# ADR-0630: evaluate autonomous return after matched private rehearsal

## Context

The accepted private comparison retains old correct actions with rehearsal but
has confidence tradeoffs. Teacher-forced fit can still fail natively, as the
earlier F readout demonstrated. Useful retention on a returning context needs
an actual game observation before more algorithm changes or infrastructure.

## Decision

Bind both saved full8/180/head36 states to the original game loop for F then
returning known A. Reuse its zero-update budget guard and existing two-phase
composition. Preserve old mode defaults, original charge/fork/clock provenance,
complete negative outcomes, native cleanup/RNG and bounded paid-prefix checks.
Freeze one small equal-maximum-interaction no-training comparison after software
gates; no target/seed/dose/metric choice or promotion.

Why this: this directly tests learned task usefulness and retained old behavior
without repeating fitting or building another runner/admission framework.

## Alternatives

Treating118accuracy as game success is unsupported. Re-fitting prefixes wastes
paid work. Re-running spent108or expanding seeds/metrics would not answer this
declared paired-endpoint question. Testing every old context now is unnecessary
to establish this bounded A-return outcome.
