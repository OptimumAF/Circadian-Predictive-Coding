# ADR-0629: private joint rehearsal with an equal-row current-only control

## Context

The affine probe acquires F and executes it natively, but old-task fit degrades.
Repeating only source/capture checks cannot improve retention. The existing
catalogue supplies arrived ABC rows and the existing private probe helper admits
two36row batches plus fixed monitors/test data within its unchanged entry limit.

## Decision

Use the original solver/helper with two fixed private arms: uniform fourfold F
repetition, then oldABC27+F9 per cue. Both use two36row fits from the identical
after-C state. Preserve original selected F data roles/release proof and old
TRAIN row provenance. No probe labels enter a benchmark replay bank. Keep
permanent attempted exposure charges before solves, completed Toy replay counts
after observed commits, bounded paid prefixes and shared original budget clocks.
The original cheaper2fit18row probe stays a separate descriptive reference.

Why this: equal row/update dimensions provide a useful control while making
old information and repeated private-F exposure explicit. They don't prove
equal runtime or isolate every order/data-distribution effect.

## Alternatives

More sequential replay overwrites this replace-head learner. Refitting original
prefixes repeats paid work. Comparing only to2fit18rows confounds exposure.
Changing metrics, seeds or dose after results invalidates the fixed comparison.
A new orchestration/budget/source-admission framework is unnecessary.

## Consequences

Joint fit retains ABC correct actions while fitting F in the observed fixed
cohort. F cross-entropy is worse than current-only, and old confidence worsens
from the starting model. Original F train/test overlap and reused TRAIN monitors
prevent heldout generalization/retention claims. Autonomous old-task return and
these new endpoints' game outcomes remain unmeasured. Source/procedure/result
review is self-review. Live status is issue118; historical trackers stay frozen.
