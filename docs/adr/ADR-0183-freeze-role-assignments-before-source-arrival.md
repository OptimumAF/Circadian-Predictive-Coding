# ADR-0183: Freeze role assignment rules before source arrival

## Context

Live development role IDs depend on class labels after source normal draws and
permutation. B exposure also selects class-balanced arrived rows, preserving their
original positions. Completed e/f validate concrete candidate/file metadata while
denying actual admission; their concrete IDs cannot serve unchanged as the actual
before-source generation representation without doing source/RNG work too early.

## Decision

Add a V2 immutable full generation request. Freeze all480 assignment recipes and
all100 source declarations/400 streams/60 bindings, complete design/identities and
all12 actual-proof obligations before source work. Keep development realizations
unset, bind policies/seeds/counts/original positions/availability and declare final
ID geometry without final values. Add a separate full concrete-role metadata bridge
to the existing e inspector. Reject its foreign schema/payload before copying or
encoding. Leave actual arrival, seeded assignment and all authority unverified.
Retain e/f APIs and all prior acceptance criteria and uncertainties.

Why this: preserving deterministic assignment rules prospectively is compatible
with the existing label-dependent split, without inventing IDs or moving source
construction early. Physical V2 and live observer proofs can be added in outer
modules through inner ports while core/app remain independent of IO/science.

## Alternatives

Predict ID realizations by reproducing source RNG: performs prohibited source-related
work at this boundary. Replace with contiguous/random partitions: changes existing
scientific controls and cannot satisfy preserved acceptance. Call concrete metadata
an actual before-source proof: its declarations do not observe chronology/arrival.
Change existing e/f schemas: breaks preserved users and accepted evidence. None adopted.

## Consequences

The new recipe gate can be tested under raising source/array/RNG/model/final/IO
guards, but it cannot certify actual code/runtime closure, lease, chronology,
untouched sources/independence, prior-effect resolution or resource/repeat/b3 gates.
A V2 physical reader and live sequential arrival ledger remain required. Complete
claims after all arrivals cannot be filled by constructing future phases early.
No actual seed selection, algorithm/baseline/metric change, dependency or experiment.
Only P6.7d2b2g may complete after its full gates and whole preservation; parents open.
