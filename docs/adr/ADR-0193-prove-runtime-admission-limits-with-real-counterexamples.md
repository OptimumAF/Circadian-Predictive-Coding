# ADR-0193 — Prove runtime admission limits with real counterexamples

Status: accepted for diagnostic evidence; full runtime admission remains open.

## Context

Public-value retention now stabilizes declared legitimate boundary observations.
Source/build/private state and non-audited transient behavior remain required.
The current V1 schema intentionally checks provided structure, not omitted membership
or complete nested endpoint routes. A filename is descriptive rather than provenance.

## Decision

Preserve production and run a bounded shared real V2/native/process hold. Compare
ordinary ephemeral MAKE_FUNCTION execution, temporary/restored defaults and the
existing direct-construction denial. Save full observations, raw code/public values,
source mismatch and exact audit events. Keep full omitted-function and missing-route
edits as historical negative controls, with the real binder rejecting the latter.
Read every artifact independently. Retain every fixture/static failure and budget.

## Alternatives

- Promoting unchanged boundary hashes to continuous proof would ignore actual misses.
- Treating a claimed filename/build string as provenance would admit mismatched code.
- Treating schema success as process completeness would admit a removed actual row.
- Editing the old graph/audit before causal controls would conceal missing coverage.

## Consequences

Seven controls demonstrate five remaining gaps while direct constructor denial and
real lease release/reacquisition work. They are mandatory inputs for the next guard/
source implementation, not full runtime admission. Public/native/build/private and
all original failed resource/arrival/prior/b3 requirements remain intact. No model
experiment, scientific dispatch, seed, metric or baseline choice is changed.
