# ADR-0560 — Joint conventional BP fit before more adaptation mechanisms

## Context

Original12update chronological native tasks fail. Saved TRAIN diagnosis shows
aligned teacher/public inputs and no label conflict, but negative commit/ready
margins. Existing default BP's ability to fit these states remains unresolved.

## Decision

Use one disposable conventional BP96update/576row fit, all six known TRAIN states
jointly available, through the existing delayed stream/native learner. Freeze
seed/policy/endpoints and use original typed tasks/effect dispatcher. Preserve
source/seed/actor/RNG/budget state and all physical failed-call costs. No stopping
or model choice from scores; existing benchmark remains unchanged.

Why this: a fit qualification distinguishes a usable conventional native path
from a base task failure before attributing anything to new circadian mechanisms.

## Alternatives

- More checkpoints or mechanism trials on the failing baseline: do not resolve
  inability to complete ordinary phases.
- Seed/horizon sweep: unneeded before a single fixed bounded qualification.
- Replace algorithms or feature schema: alignment evidence does not justify it.

## Consequences

The sole case fits6/6and completes both ordinary/stale tasks, refusing both
revocations. Known-template native task ability is now observed; chronology,
untrained-context learning, reliability and comparative benefit remain open.
Joint availability/order and16times row exposure prevent a causal dose claim.
Reuse qualified full state for the next new-context increment, preserving prior
charges and momentum rather than reconstructing a parameter-only learner or
repeating warmup. No new general loader/orchestration framework is warranted.
