# ADR-0441: Measure existing H32 endpoint phases without callback authority

## Context

The original-source H32 game quartet cannot complete under declared60s endpoints
and240s whole-case limits. Total elapsed time alone cannot separate native learner
prediction from preservation, public input work and physics. No larger clock or
new algorithm is justified by this missing attribution.

## Decision

Instrument four inclusive elapsed phases in the existing evaluator. Aggregate
counts/time and unknown intervals only; no per-call history or new runner. Ordinary
H32 observers save the profile in their existing protected paid record. Old count
and direct-default behavior remains unchanged. Budgets and clocks retain their
original authority; diagnostics do not authorize work or promotion.

Why this: measurable cost is a prerequisite for a proportional performance change.
Production requires the exact native-clock recorder and directly reads system
perf_counter. An injected callback could change source state after a preservation
proof or before prediction. Keep injection in the base helper/private scripted
tests; replacing its inherited callback field is inert in the native recorder.

## Alternatives

Raising clocks/repeating a quartet does not identify the bottleneck. A final-only
extra guard misses callback mutations before prediction. Rechecking after every
diagnostic callback adds large cost and duplicates the preservation machinery.
Another orchestration or audit framework does not help attribution.

## Consequences

Counts, failure evidence and independent deadlines are preserved. Failed timing
reads produce unknown intervals without masking original errors. Inclusive spans
must not be summed as total time; adapter work remains inside prediction and
setup/copies/serialization are additional. Empty-span overhead is engineering
metadata, not native latency or learning evidence. All original scientific and
release claims remain open.
