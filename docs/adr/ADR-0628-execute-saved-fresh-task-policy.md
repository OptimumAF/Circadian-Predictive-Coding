# ADR-0628: execute the saved fresh-task policy before and after private learning

## Context

The accepted isolated affine F probe fits its reserved task while degrading
readonly old-task predictions. Saved full states exist before and after its two
fits; native learned F execution is unmeasured. More checkpoint infrastructure
wouldn't answer whether the learned task is useful.

## Decision

Bind both exact states to the original evaluator's F probe_test plan, using a
narrow scripts composition module and a mutually exclusive existing CLI mode.
Reuse native state conversion, public history, raw K7 decisions, RNG and cleanup
guards. Require completed preceding evidence, while allowing completed negative
game outcomes. Preserve source bytes, original clocks/charges, separate observed
cursors and bounded paid prefix copies. Budget one no-training native comparison
only after focused software gates and self-review.

Why this: endpoint reuse avoids repeated training and separates teacher-forced
fit from autonomous execution using an ordinary, already qualified game loop.

## Alternatives

Refitting the prefixes would repeat paid work. Another orchestration/manifest
system would duplicate existing ports. Selecting a different seed, dose, metric
or geometry after results would invalidate the fixed comparison. A full sweep
is premature for this descriptive outcome.

## Consequences

Both endpoint limits and all sunk costs remain explicit. The route requires
local accepted research evidence; normal portable play remains separate.
Identical original F train/test transitions prevent a generalization claim.
No old-task native recovery, CPC advantage, independent review or repository-wide
release acceptance follows. Live scope/status stays in issue117; historical
plans and logs remain frozen under AGENTS.md.
