# ADR-0509: test one fixed prefix/group-balanced correction recipe

## Context

Uniform112→120 correction fitting lowers mean error but worsens the first action
and original expert fit; all four native120 scenes fail. Native weighted math and
recorded continuation are qualified. Useful adaptation remains unresolved.

## Decision

Use the existing study and one predeclared148-row/eight-update weighted recipe,
equal ideal group mass and half correction mass on its first row. Keep original
source112, data, dose, learner, normalization, seeds and all metrics. Reuse accepted
uniform120 physical control and uniform112/120 diagnostics; validate exact source,
prior work and original input/dose before new weighted work. Measure balanced120
detached TRAIN fit and all four existing native scenes. Keep negative outcomes.

## Alternatives

- Another correctness/provenance increment: prerequisites already pass.
- Additional uniform dose or a weighting sweep: introduces another choice before
  answering the single diagnosed prefix/group question.
- New learner or runner: unnecessary for this conventional repair hypothesis.

## Consequences

One fixed recipe helper and explicit existing-study flag, no new framework or
dependency. Charge reconstruction, weighted work, diagnostics, native controls,
memory and time. Equal update/row dose does not imply equal total computation.
Negative results can answer the research question; physical usefulness, reliable
adaptation, CPC benefit, broader lanes and release readiness remain open.
