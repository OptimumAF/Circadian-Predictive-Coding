# ADR-0553 — Compose catalog CLM learning with the existing local workflow

## Context

The repository already has CLM catalog learning and frozen typed inference, plus
a local workflow with real bounded multi-step effects. Probability-only stream
readouts cannot demonstrate completion, stale-state recovery or permission
enforcement. Existing conventional and Open-Jev outcomes provide references and
include important wrong-completion negatives.

## Decision

Use the same twelve consented TRAIN demonstrations in eight explicit catalog
batches through the existing delayed inbox. Encode only their public text once,
keep the original directional objective and native projection geometry. After
all updates, bind independent unchanged/learned frozen typed heads to the shared
encoder and run the existing three perturbation episodes per control.

Keep original loaded/trained/copy owners, RNG and permanent work separate. Exactly
one binding snapshot is charged after sealed TRAIN work. Preserve paid failures,
trusted original scalar prefixes and unknown pending effects. No new runner,
learning rule, dependency, handler or promotion authority.

Why this: it delivers actual TRAIN-to-effects functionality using established
ports. A separately budgeted native observation can then measure useful behavior,
without treating correct probability plumbing as task success.

## Alternatives

Adding more readout/capture counts would not exercise actions. Replacing the
dispatcher with a tool handler would add unnecessary external authority. Reusing
paired consolidation receipts for directional catalog training would substitute
a different objective silently. Source optimizer continuation or restored budget
authority is unnecessary for the fixed fresh workflow learner.

## Consequences

Actual typed decisions invoke the frozen encoder, adding inference work to head
training. Endpoint quality may remain mixed or fail; all results are valid.
Equal source information does not imply equal model/pretraining access or total
compute. Literal integration and source guards do not establish native competence,
calibrated quality, circadian benefit or general host containment.
