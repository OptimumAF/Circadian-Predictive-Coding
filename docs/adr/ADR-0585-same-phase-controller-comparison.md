# ADR-0585: Compare current-policy outcomes against the same phase

## Context

The existing policy stream changes task truth and active tools. An unchanged
v2-qualified source fails v1 tasks and passes v2; a cross-policy success difference
would falsely resemble acquisition. The original controller study uses another
grouping and its final metrics must remain unchanged.

## Decision

Add an explicit mode to the existing comparison/CLI. Freeze the original fitted
chooser/source and all five references, data/order/limits/metrics before numerical
work. Complete and validate all five deferred candidates before development
readouts. Check previously accepted evidence before more work and all frozen
records during scoring; retain paid prefixes on failures.

Use all fixed phase ends4/8/12, invoice+parcel six current outcomes and password
three unchanged outcomes. Compare each with no_learning under the SAME phase and
policy. Verify actual sandbox final truth and complete/unique/role-bound outcomes.
Use original unit cost weights/directions, explicit partial wall/RSS proxies and
unknown all-in fit overhead. Old study grouping/final data stay untouched. No new
runner, model schema, fitting, permission or training authority is introduced.

Why this: source behavior under changed truth is not learning. Same-phase controls
answer whether update choices improve outcomes beyond the fixed source.

## Alternatives and consequences

- Score cross-policy raw helper gains: rejected; truth/mask changes confound them.
- Refit the chooser or tune a reference from these outcomes: rejected; test its
  original fixed behavior instead.
- Reuse issue68 timing as training-only cost: unsuitable; its combined callback
  includes readouts/startup. Periodic is re-observed under the new deferred-cost
  procedure, while its full phase states are verified equal to the saved case.
- Infer efficiency from raw utility ranking: unsupported. First-case time and
  sampled memory differ, despite identical task outcomes. Keep every value and
  report uncertainty; do not warm up/rerun to select a nicer ranking.

The sole cohort yields22SGD132rows, zero task gain versus no_learning, unchanged
password retention and identical fitted/drift actions/full phase states. Raw
utilities are all negative; fitted's numerically highest value is a cost-proxy
difference, not established advantage. Full R7.5/G7/science/release remain open.
Self-review is not independent acceptance. Evidence: issue69 and
`artifacts/runs/phase-matched-controllers-20261023/RESULTS.md`.
