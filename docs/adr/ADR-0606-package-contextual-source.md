# ADR-0606: Package the qualified contextual source for the CPU example

## Context

The conventional guarded learner has accepted new-task/retention behavior, but
its documented command requires an ignored local research source. Existing CPU
package data already supports recorded ticket and memory examples.

## Decision

Bundle the exact qualified source77 record under that existing package-data
pattern, with synthetic data provenance/MIT/history/limitations. Add a bounded
infra context manager and an explicit source alternative in the existing CLI,
permitted only for the accepted synchronous guarded example. ExitStack retains
extracted resources through report publication. Original source/default routes,
guards, limits and failed research evidence remain.

Why this: a usable installed learning example advances reproducibility without
another learner, comparison, source reconstruction or orchestration framework.

## Alternatives

Recreating the source would pay for redundant baseline work and change evidence.
Implicit source fallback would hide the selected data and mode. Exposing every
research mode would imply unsupported controller/probe/source qualifications.

## Consequences

Adds277216bytes of project-owned synthetic data; no new runtime dependencies.
Metadata and installed execution qualify the delivery path only. Known-template
success does not prove broader scientific, optional GPU/hardware or release
readiness. Loading weights never restores old authority or renews budgets.
