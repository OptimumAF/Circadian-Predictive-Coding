# Private fresh-task rehearsal with an equal-row control

The existing CLI compares two private fits per cue recipe without changing the
benchmark learner or collecting more demonstrations:

```powershell
.\.venv\Scripts\python.exe -m scripts.run_minigrid_linear_fit_control --context-linear-rehearsal --describe
.\.venv\Scripts\python.exe -m scripts.run_minigrid_linear_fit_control --context-linear-rehearsal --source artifacts/runs/affine-fresh-task-probe-20261024/actual.json --retained-source artifacts/runs/catalogue-capacity-new-c-20261024/actual.json --output new-private-rehearsal.json
```

The second command requires the qualified local111/113 reports and bundled
TRAIN asset, NumPy and a prospective local budget. No MiniGrid runtime/teacher
is called. Existing outputs and fit overrides are refused. The completed study
must not be rerun under a new filename; a different experiment needs its own
prospectively frozen protocol. Normal portable play/default probe modes remain.

Why this: [the original private probe](affine-fresh-task-probe.md) learns F but
loses old-task fit; [native F readout](affine-fresh-task-games.md) proves useful F
execution. Joint fitting can rehearse the already-arrived ABC examples without
adding a training framework. An equal-row current-only control separates the
old-information opportunity from simply increasing F row exposure.
