# Original published experiment register

This dated register binds the named results and evidence families in the frozen repository documentation to their original saved records. It covers the existing documentation and available original record inventory; it does not recover missing historical execution facts.

Why this: a command, a related feasibility request and a current installation can each record different facts. Dependency assertions therefore stay with their actual original file and JSON pointer. A derived report retains upstream assertions without turning them into its own execution environment.

## Evidence and scope

- [Complete machine-readable register](../constraints/published-run-environments-2026-10-06.publications.json): all source identities, exact claim paragraphs/sections, record identities, original saved dependency pointers, document roles and every reference disposition.
- [Original metadata ledger v2](../constraints/published-run-environments-2026-10-06.v2.json) and its lossless saved-field sidecar remain unchanged. The earlier v1 ledger remains unchanged.
- Current tested dependencies and fresh installation checks are documented separately in [dependency reproducibility](dependency-reproducibility.md). They are not assigned to historical results.
- All recorded metrics, rankings, seeds, baselines and failed attempts remain unchanged. Repeated/derived inputs are not counted as independent replications.
