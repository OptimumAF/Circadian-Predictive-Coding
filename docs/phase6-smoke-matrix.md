# Phase 6 smoke coverage matrix

P6.1 checks that the existing public experiment branches run on bounded,
deterministic fixtures and that every output they promise can be read back.
It is a functionality gate. Scores, relative rank, and fitted sleep thresholds
are outside this gate. The fixed v14 study identity and all historical result
bytes remain unchanged.

**Why these cells:** The checkout exposes several public runners, not one
experiment switch. A smoke of only the fixed v14 path would miss configurable
NumPy, optional Torch, and derived artifact writers. Conversely, rerunning
the large CIFAR studies would turn a correctness check into a new experiment.
The named paths below come from the current README, `scripts/`, CLI choices,
and artifact adapters. A row is not complete merely because an older study
produced a result; its bounded branch/output check must be explicit.

Every cell must check finite, parseable output; declared protocol/config/seed
identity; all expected rows/files; a forced event where supported; a no-sleep
or stationary control; and refusal of accidental overwrite or stale/partial
input. Reproducibility comparisons exclude wall-clock durations and other
measured resource noise, as documented in `reproducibility-scope.md`.
Unavailable optional dependencies or data must be reported as skips or
blockers, never counted as covered branches. The P6.1 parent is complete
because every enabled bounded cell and output family has evidence; live CUDA
studies and unavailable original CIFAR-100 figure inputs remain outside it.
