# Isolated conventional BP ticket-fit qualification

The original chronological native case failed; its TRAIN diagnosis found aligned
inputs but wrong phase decisions. This fixed qualification asks whether existing
BP can fit the six teacher states **jointly** before another adaptation mechanism.

```powershell
python -B -m scripts.qualify_ticket_bp_fit --output fresh-bp-qualification.json
```

Runs real native TRAIN. Requires the existing CPU Torch environment, no new
dependency/download. Use the fixed [protocol](../artifacts/runs/bp-ticket-fit-qualification-20261023/PROTOCOL.md)
for its declared scope; no sweep, early stopping or favorable checkpoint choice.
Output must be fresh. No command-line seed/dose/width selection is added.

benchmark/deployed objects and recorded failures are untouched.

extension. New helper logic adds no learning rule or scheduler/framework.

The task readout guards full source/seed/local actor/budget and full frozen
native readout before/after calls. Teacher projection is separately charged.
Private native copy access is a trusted synchronous recipe detail, not hostile
Python containment or concurrent serving/promotion. The recorded local actor is
the qualification's fresh stable actor, not an external deployed application.
